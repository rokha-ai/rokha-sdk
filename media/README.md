# Official Rokha media

Brand and marketing images for anyone making content about Rokha: posts, threads, videos, articles and community cards. The same files are served at https://rokha.ai/media/ and listed by the API (`GET https://rokha.ai/api/media`) and the MCP tool `media_library`.

## Usage

Official Rokha media. Free to use when talking about Rokha: posts, threads, videos, articles, community cards. Don't alter the logo or wordmark, don't imply endorsement of another product, and keep paid posts labelled (#ad / paid partnership).

- Link back to https://rokha.ai or the CTA listed for an image when you can.
- An image marked **Caution** shows illustrative numbers or sample boards. Use it for the idea, never as proof of real figures.
- `manifest.json` is the machine-readable version of this page (topics, sizes, alt text, where each image fits).
