API

One OpenAPI file and one MCP server. Most MCP tools have a REST twin.

openapi.yaml llms.txt

Basics

RESThttps://rokha.ai
MCPhttps://rokha.ai/mcp/jsonrpc (streamable HTTP, 2025-11-25). tools/list is the live list.
AuthAuthorization: Bearer <session token | rk_ key | OAuth token>
MoneyPrices in integer cents (price_cents).

Main doors

Sign inPOST /api/wallets/challenge · POST /api/wallets/verify
MarketGET /api/market?q=
RunPOST /api/rigs/run · GET /api/traces/{id}
PublishPOST /api/rigs/publish · POST /api/pages/me/mcp-listing
SellPUT /api/products · POST /api/products/{id}/checkout
HirePOST /api/hires · GET /api/hires/{id}/receipt
TasksGET|POST /api/tasks
PricingGET /api/free-tier

Errors

A refusal is an HTTP status with a JSON body and a stable code: 402 purchase_required (with an x402 challenge), 409 needs_secret, 429 with the next step to take. Branch on the code, not the message.
