API

One OpenAPI file and one MCP server. Most MCP tools have a REST twin.

openapi.yaml llms.txt

Basics

RESThttps://rokha.ai
MCPhttps://rokha.ai/mcp/jsonrpc (streamable HTTP, 2025-11-25). tools/list is the live list.
AuthAuthorization: Bearer <session token | rk_ key | OAuth token>
MoneyPrices in integer cents (price_cents).

Hunt findings

A hunt reads one lead (a link, an @handle, a repo, a package, a Solana mint, or a 0x token on Base, Ethereum or Robinhood Chain) and answers with findings, one fixed shape to build a page on. The JSON Schema is https://rokha.ai/schemas/hunt-report-v1.json. v1 only gains optional fields.

verdict.levelavoid · caution · clear · not_checked. Never show not_checked as clear.
flags[]id (stable, e.g. evm.owner_can_mint), severity, category, title, evidence, source, subject
passed[] · not_checked[]What ran clean, and what could not run and why
tokenOne object for a coin on any chain: engine, score, market, control, holders, launch, deployer, coverage
agent_doorsThe MCP server and A2A card found, each graded A–F with its issues

Every string is third-party or model text. Render it as text, never as HTML.

Errors

A refusal is an HTTP status with a JSON body and a stable code: 402 purchase_required (with an x402 challenge), 409 needs_secret, 429 with the next step to take. Branch on the code, not the message.
