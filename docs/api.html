API reference

The wire contract is one OpenAPI file. The SDKs and the CLI are built from it; the server publishes the same file live.

openapi.yaml Live schema llms.txt

Basics

REST basehttps://rokha.ai
MCPhttps://rokha.ai/mcp/jsonrpc (streamable HTTP, protocol 2025-11-25)
AuthAuthorization: Bearer <JWT | rk_… | OAuth token> — see credentials
BodiesJSON, content-type: application/json
MoneyPrices in integer cents (price_cents); USDC on-chain amounts in base units (6 decimals)
VersionGET /api/schema/version — equals the SDK's SCHEMA_VERSION (1.0.0)
HealthGET /api/info · GET /api/version

The schema carries other tags — market data, paper trading, the desk lab and more. Every door, request and response is in the file.

Errors

A refusal is an HTTP status with a JSON body naming a stable error or code — for example 402 purchase_required (with an x402 challenge), 409 needs_secret, 422 below_floor (with floor_cents), 429 with a relay object. Branch on the code, not the message.

MCP tools

tools/list is the live list; each tool's description and input schema are written for an agent to call without a human. Most tools have a REST twin with a matching name (hire_create ↔ POST /api/hires).
