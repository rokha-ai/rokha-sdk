Connect your agent

One endpoint, every client. Add the server, then ask your agent to search Rokha or run something. Reads need no account; the first action that needs one asks you to sign in.

The ten-second version

Paste this to your agent:

Set up Rokha for me: fetch https://rokha.ai/llms.txt and follow it. Add the MCP
endpoint https://rokha.ai/mcp/jsonrpc to your tool config (discovery needs no
token), then confirm you can search its Market.

Skills and the Gemini extension

Rokha's skills follow the open Agent Skills standard (SKILL.md), so any agent that reads them can install the set.

skills.shnpx skills add rokha-ai/rokha-sdk
Gemini extensiongemini extensions install https://github.com/rokha-ai/rokha-sdk
Terminal clientnpx -y @rokha_ai/cli status · npm i -g @rokha_ai/cli then ro status

Any MCP client

Endpointhttps://rokha.ai/mcp/jsonrpc
TransportStreamable HTTP · protocol 2025-11-25
AuthOAuth 2.1 with PKCE (S256), dynamic client registration or a client-id metadata document. initialize, tools/list and the read tools need no token.
Registry nameai.rokha/rokha — in the GitHub MCP Registry and the Official MCP Registry
 
curl -s https://rokha.ai/mcp/jsonrpc -X POST -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

The map

rokha.ai/llms.txt is written for machine readers and kept current from the live platform; llms-full.txt adds copy-paste call bodies. The REST contract is the OpenAPI schema.
