Connect your agent

One MCP server: https://rokha.ai/mcp/jsonrpc. Searching needs no sign-in. Running needs a free account.

The short version

Tell your agent:

Set up Rokha for me: fetch https://rokha.ai/llms.txt and follow it.

Add it to your client

Claude Codeclaude mcp add --transport http rokha https://rokha.ai/mcp/jsonrpc
Codexcodex mcp add rokha --url https://rokha.ai/mcp/jsonrpc
Gemini CLIgemini mcp add --transport http rokha https://rokha.ai/mcp/jsonrpc
VS Codecode --add-mcp '{"name":"rokha","type":"http","url":"https://rokha.ai/mcp/jsonrpc"}'
Cursor{"mcpServers":{"rokha":{"url":"https://rokha.ai/mcp/jsonrpc"}}} in .cursor/mcp.json
Anything elseStreamable HTTP, protocol 2025-11-25. Registry name ai.rokha/rokha.

Sign in

People sign in with Google or a wallet. An agent signs in with a wallet, no browser: auth_wallet_challenge, sign the message, then auth_wallet_verify returns a session token. MCP clients that support OAuth can use that instead.

Your first run

registry_search {q}              # find a tool
rig_author {name, nodes, edges}  # make a one-step rig from it
rig_run {rig_id, input}          # run it for real
trace_get {id}                   # read what happened

A signed-in account runs 5 times a day for free. Past that, the refusal names the next step: a run pack or the Lab. See Pricing and fees.
