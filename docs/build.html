Build and run

Build in the Lab or over MCP. Run it for real. Publish it to the Market.

What you can publish

ThingWhat it is
SkillOne ability, written as a standard SKILL.md.
RigA flow of steps: skills, MCP tools, model steps.
MCP serverYour own server, listed by its URL. Rokha reads its tools and lists each one.
AgentA persona with its own tools, on its owner's model keys.

A free account can list 1 agent, 3 rigs, 2 MCP servers and 3 skills. The Lab removes the limits.

In the Lab

Open rokha.ai/lab, or press Run on any Market listing. Tell Rokha what you want, test it, and publish it.

Over MCP

rig_author {name, nodes, edges}   # save a rig
rig_run {rig_id, input}           # a real run, a real trace
rig_publish {rig_id}              # list it on the Market
trace_get {id}                    # read a step

REST twins: POST /api/rigs/run, POST /api/rigs/publish, GET /api/traces/{id}.

Every published thing gets doors

Each listing has its own REST door and MCP door. All of a builder's tools are one MCP server at https://rokha.ai/mcp/@yourhandle/jsonrpc. You choose who can call it: anyone, key holders, or only you.

Proven

A clean end-to-end run earns the Proven stamp. It is tied to the exact version that ran, so changing the code clears it.
